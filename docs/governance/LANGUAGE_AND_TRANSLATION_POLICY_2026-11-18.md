# BoxVia / ANDEKS - Language and Translation Policy
Date: 2026-11-18
Status: OWNER-APPROVED WORKING RULE
Scope: normative documents, public BoxVia website, and associated collaboration
Working branch: work/technical-pilots-first-20261118

## 1. Normative documentation (ANDEKS)
- Russian is the working language for drafting, discussion and review.
- English is the output language for normative documents.
- Technical translation is mandatory for normative deliverables.
- Preserve normative meaning, defined terms, assessment boundaries, evidentiary status, limitations and degree of certainty.
- Do not introduce obligations, guarantees, conclusions or claims absent from the source.

## 2. Public BoxVia website
- The public website is English-only.
- Website design, implementation discussion, copy review and acceptance are conducted in Russian.
- Technical translations into Russian are provided within working chats when needed for review or clarification.
- Such chat translations are not a requirement to publish Russian pages.
- English website copy must be semantically faithful to the approved Russian-language working decisions.
- No RU/EN language switcher, mirrored Russian routes or bilingual publication is required under this rule.

## 3. Editorial conventions
- Do not use em dash (U+2014) or en dash (U+2013) in authored copy; use the short hyphen where appropriate.
- Do not use Russian letter yo (U+0451/U+0401) in Russian working/publication text.
- Preserve technical syntax and identifiers when a literal character is required by a tool or format.

## 4. Acceptance and precedence
- For the website, English-language completeness and semantic fidelity are acceptance criteria.
- Missing Russian website pages or translations are NOT grounds for RETEST.
- For ANDEKS normative deliverables, English technical translation remains mandatory.
- This owner-approved clarification supersedes any earlier site plan language that implied mandatory bilingual website publication.
- This policy does not retroactively change normative-document translation requirements.
- This policy does not authorize production deployment.
