ARE - ANDEKS Runtime Engine

ARE is the technical engine behind ERA, our system for assessing evidence. Explore the public documentation to see how the projects fit together.

Open public repository

How the projects connect

ARE provides the underlying engine. ERA - Evidence Readiness Assessment - is built on ARE and examines the evidence available for a specific claim.

ANDEKS™ supplies a separate normative system for independent assessment. Each result has its own scope and conditions.

What you can explore

  • ARE overview - an introduction to the engine.
  • Architecture - how ARE and ERA relate.
  • Evidence demonstrator - a worked example using synthetic material.

The repository publishes selected documentation and an illustrative example. Engine source code and deployment instructions remain private. The example illustrates the method through documents, with software execution and production readiness outside its scope.
